# PWA Icons TODO

The following placeholder icons are needed for the PWA manifest:

- `icon-192.png` - 192x192px app icon (PNG format)
- `icon-512.png` - 512x512px app icon (PNG format)

## Recommended Design

- Use bee/honeycomb theme with amber (#f59e0b) color
- Simple, recognizable design that works at small sizes
- Solid background color for better visibility
- Consider using a beehive or stylized bee icon

## Tools

You can use:
- Figma/Canva for design
- Online icon generators (e.g., maskable.app)
- Adobe Illustrator/Photoshop

## Maskable Icon (Optional)

Consider creating a maskable icon variant for better platform support:
- Add `"purpose": "maskable"` to manifest icons
- Ensure critical elements are within the safe zone (80% of canvas)
