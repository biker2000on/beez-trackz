# Beez Trackz Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a self-hosted, AI-first beekeeping management PWA for tracking apiaries, hives, inspections, queens, equipment, feeding, honey harvest/sales with audio/video transcription and AI recommendations.

**Architecture:** Next.js 15 App Router monolith with Server Components and Server Actions. PostgreSQL for data, Redis + BullMQ for background jobs (transcription, AI processing). Drizzle ORM for type-safe database access. PWA with offline support via @serwist/next.

**Tech Stack:** Next.js 15, TypeScript, Drizzle ORM, PostgreSQL 16, Redis, BullMQ, Tailwind CSS, shadcn/ui, React-Konva, react-flow, Vitest, @serwist/next

**Design doc:** `docs/plans/2026-02-14-beez-trackz-design.md`
